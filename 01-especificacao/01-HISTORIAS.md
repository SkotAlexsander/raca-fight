# 01 — Histórias de uso

Este arquivo lista, em frases curtas, o que cada pessoa quer fazer no app e para quê.
Cada história tem um número (H01, H02…) para ser citada nos fluxos, nas telas e no código.

Formato: **Como [papel], quero [ação] para [resultado].** Quando a história depende de uma pendência do P00, está marcada **[decidir]**.

## A. Entrada e conta

- **H01** — Como visitante, quero criar uma conta com e-mail ou telefone e senha para começar a usar o app.
- **H02** — Como visitante, quero entrar com conta Google ou Apple para não precisar lembrar outra senha.
- **H03** — Como aluno, quero me vincular à minha academia (por código da academia ou convite da recepção) para que ela me enxergue e eu veja os treinos prontos dela.
- **H04** — Como aluno, quero usar o treino livre mesmo sem estar vinculado a uma academia ainda, para não ficar travado enquanto espero a confirmação.
- **H05** — Como pessoa com dois papéis (aluno e instrutor), quero trocar de visão sem sair da conta para não ter duas contas.
- **H06** — Como usuário, quero recuperar a senha pelo e-mail ou SMS para voltar a entrar quando esquecer.
- **H07** — Como usuário, quero sair da conta neste aparelho para proteger meus dados num celular emprestado.
- **H08** — Como usuário, quero exportar e apagar meus dados para exercer meus direitos (LGPD).

## B. Perfil e cadastro corporal

- **H09** — Como aluno, quero preencher peso, altura, data de nascimento, objetivo, restrições e quantos dias por semana pretendo treinar para que o app e a academia planejem melhor para mim.
- **H10** — Como aluno, quero pular o cadastro corporal e preencher depois, para não ser obrigado a nada no primeiro dia.
- **H11** — Como aluno, quero registrar um peso novo de vez em quando para acompanhar minha evolução num gráfico simples.
- **H12** — Como aluno, quero mudar meu objetivo quando ele mudar para que os treinos prontos sugeridos acompanhem.
- **H13** — Como aluno, quero escolher se a academia pode ver meus dados corporais para ter controle sobre quem enxerga informação de saúde minha.
- **H14** — Como aluno, quero ver quem tem acesso aos meus dados hoje (academia, personal) para saber a quem autorizei.

## C. Treino livre

- **H15** — Como aluno, quero criar um treino do zero com nome e dias (A, B, C ou "Peito e tríceps") para organizar minha semana.
- **H16** — Como aluno, quero buscar um exercício na biblioteca por nome ou grupo muscular e adicioná-lo a um dia do treino para montar a sequência.
- **H17** — Como aluno, quero definir séries, repetições, carga e descanso de cada exercício para saber o que fazer na hora.
- **H18** — Como aluno, quero reordenar exercícios arrastando para deixar na ordem em que treino.
- **H19** — Como aluno, quero duplicar um dia ou um treino inteiro para não remontar tudo quando só muda um detalhe.
- **H20** — Como aluno, quero criar um exercício que não existe na biblioteca (só com nome) para não ficar preso ao que a academia cadastrou.
- **H21** — Como aluno, quero guardar vários treinos e escolher qual está ativo para alternar entre fases sem perder nada.

## D. Treinos prontos por objetivo

- **H22** — Como aluno, quero ver os treinos prontos da minha academia filtrados pelo meu objetivo para não precisar olhar tudo.
- **H23** — Como aluno, quero abrir um treino pronto e ver os dias e exercícios antes de escolher para saber se cabe na minha rotina.
- **H24** — Como aluno, quero usar um treino pronto como meu treino ativo para começar a treinar hoje.
- **H25** — Como aluno, quero ajustar a carga e as séries de um treino pronto que adotei para adaptar ao meu nível sem perder a estrutura.
- **H26** — Como aluno sem objetivo informado, quero ver todos os treinos prontos para não ser bloqueado por não ter preenchido o perfil.
- **H27** — Como funcionário, quero criar um treino pronto com nome, objetivo(s), nível e dias para a biblioteca da academia.
- **H28** — Como funcionário, quero arquivar um treino pronto antigo para ele sumir da lista do aluno sem apagar quem já o usa.

## E. Execução do treino (o dia de treino)

- **H29** — Como aluno, quero abrir o app e ver qual é o dia de treino de hoje para não pensar: só começar.
- **H30** — Como aluno, quero marcar cada série feita com repetições e carga reais para registrar o que de fato fiz.
- **H31** — Como aluno, quero ver a carga que usei da última vez em cada exercício para decidir se subo.
- **H32** — Como aluno, quero um cronômetro de descanso que avisa quando acabou para não ficar olhando o relógio.
- **H33** — Como aluno, quero pular ou trocar um exercício na hora (aparelho ocupado) para não travar o treino.
- **H34** — Como aluno, quero encerrar o treino e ver um resumo (tempo, séries, volume) para sentir que fechou o dia.
- **H35** — Como aluno, quero registrar o treino mesmo sem sinal de internet na academia para não perder o que fiz; sincroniza depois.
- **H36** — Como aluno, quero registrar que treinei num dia passado (esqueci de abrir o app) para o histórico ficar certo.
- **H37** — Como aluno, quero ver meu histórico por semana e por exercício para acompanhar a evolução.

## F. Acompanhamento pela academia

- **H38** — Como funcionário, quero ver a lista de alunos da academia com busca por nome para achar quem está na minha frente.
- **H39** — Como funcionário, quero abrir o perfil de um aluno e ver dados corporais (se autorizou), objetivo, treino atual e última vez que treinou para orientar na sala.
- **H40** — Como funcionário, quero montar um treino para aquele aluno direto no perfil dele para que ele chegue amanhã com o treino no celular.
- **H41** — Como funcionário, quero começar o treino do aluno a partir de um treino pronto e ajustar, para não montar do zero toda vez.
- **H42** — Como funcionário, quero ver quais alunos não treinam há mais de 14 dias para a recepção chamar.
- **H43** — Como funcionário, quero vincular um aluno novo (que acabou de se matricular) à academia para ele aparecer na lista.
- **H44** — Como funcionário, quero confirmar ou recusar o pedido de vínculo que um aluno fez pelo código para evitar gente de fora na lista.
- **H45** — Como funcionário, quero cadastrar um exercício novo na biblioteca com nome, grupo muscular e um texto curto de como fazer, para os treinos ficarem completos.

## G. Plus (personal, treino, dieta, conversa)

- **H46** — Como aluno, quero entender o que o Plus inclui e quanto custa antes de assinar para decidir com clareza.
- **H47** — Como aluno, quero assinar o Plus para ter um personal me acompanhando pelo app. **[decidir]** Pago no app pelo aluno · Ligado pela academia, que cobra junto da mensalidade.
- **H48** — Como aluno Plus, quero saber quem é meu personal (nome, foto) para saber com quem falo.
- **H49** — Como aluno Plus, quero ver o treino que o personal montou e segui-lo como meu treino ativo para treinar o que foi planejado para mim.
- **H50** — Como aluno Plus, quero ver a dieta do dia (refeições e itens) para saber o que comer.
- **H51** — Como aluno Plus, quero marcar cada refeição como feita para o personal ver se estou seguindo.
- **H52** — Como aluno Plus, quero avisar quando não segui uma refeição (e escrever o motivo) para o personal ajustar.
- **H53** — Como aluno Plus, quero conversar com meu personal para tirar dúvida sem esperar o dia de ir à academia. **[decidir]** Chat no app · Abre o WhatsApp.
- **H54** — Como aluno Plus, quero cancelar o Plus e saber até quando ele vale para não ser cobrado sem querer.
- **H55** — Como personal, quero ver só os meus alunos Plus para focar em quem é meu.
- **H56** — Como personal, quero abrir o aluno Plus e ver dados corporais, histórico de treino e adesão à dieta para ajustar o plano.
- **H57** — Como personal, quero montar e ajustar o treino do aluno Plus para o treino dele refletir o acompanhamento.
- **H58** — Como personal, quero montar a dieta em refeições e itens para o aluno seguir no dia. **[decidir]** Texto livre por item · Item escolhido de um banco de alimentos com gramas e macros.
- **H59** — Como personal, quero copiar a dieta de uma semana para a seguinte e mudar só o necessário para não redigitar.
- **H60** — Como personal, quero receber aviso quando o aluno Plus não registra treino ou refeição há 3 dias para chamar antes de ele desistir.

## H. Visão do dono

- **H61** — Como dono, quero ver quantos alunos ativos, quantos Plus e quantos treinos foram registrados nesta semana para saber se a academia está viva.
- **H62** — Como dono, quero cadastrar funcionários e personais e definir o papel de cada um para a equipe entrar no app.
- **H63** — Como dono, quero designar um personal a cada aluno Plus (e trocar) para a conta fechar.
- **H64** — Como dono, quero ver quantos alunos Plus cada personal tem para equilibrar a carga.
- **H65** — Como dono, quero ver os alunos que pararam de treinar para a equipe agir.
- **H66** — Como dono, quero remover um funcionário que saiu para ele perder o acesso na hora.
- **H67** — Como dono, quero definir o código de vínculo da academia (e trocar) para controlar quem entra.
- **H68** — **[decidir]** Como dono, quero controlar mensalidade, catraca e caixa no app · Fica fora da v1 (ver `05-FORA-DA-V1.md`).

## I. Cronômetro

Acrescentado em 10/10/2026 (agente H, P07). Ficam com H69 a H76, a faixa que o agente G (avisos, escrito ao mesmo tempo) deixou para o cronômetro. O descanso entre séries (H32) usa o mesmo cronômetro.

- **H69** — Como aluno, quero um cronômetro **livre**, que conta para cima e marca voltas, para medir o cardio e a esteira.
- **H70** — Como aluno, quero uma **contagem regressiva** com o tempo que eu escolher, que vibra no fim, para a prancha, o alongamento ou um tiro na esteira.
- **H71** — Como aluno, quero um cronômetro **intervalado** (trabalho, descanso e rodadas), com Tabata, EMOM e HIIT já prontos, para fazer o meu HIIT sem abrir outro app.
- **H72** — Como aluno, quero abrir o cronômetro pelo treino em andamento ou pelo Início, mesmo sem treino aberto, para usá-lo a qualquer hora.
- **H73** — Como aluno, quero que o tempo continue certo com a tela bloqueada e que o celular avise o fim e cada troca de fase, para poder deixar o celular no bolso ou no suporte da esteira.
- **H74** — Como aluno, quero salvar o tempo do livre ou do intervalado como uma série de um exercício por tempo, para o cardio entrar no meu histórico.
- **H75** — Como aluno, quero que a série por tempo (a prancha de 30 s) conte sozinha e fique marcada no fim, para não tocar no celular durante a série.
- **H76** — Como aluno, quero ler o tempo a um metro de distância, para não precisar pegar o celular entre um esforço e outro.
